# DataVine Analytics – Machine Learning Prototypes

This project demonstrates three machine learning applications using standardized datasets:

1. **Wine Classification (Wine Dataset)**

   * k-Nearest Neighbors (k-NN)
   * PCA for dimensionality reduction
   * Hyperparameter tuning with GridSearchCV

2. **Agricultural Recommendation System (Chickwts Dataset)**

   * PCA-based feature transformation
   * Cosine similarity for feed recommendations

3. **Crime Pattern Analysis (USArrests Dataset)**

   * K-Means clustering
   * Gaussian Mixture Models (GMM)
   * PCA for visualization and pattern discovery

The notebook follows a complete machine learning workflow, including data preparation, standardization, dimensionality reduction, model implementation, evaluation, visualization, and interpretation of results.
